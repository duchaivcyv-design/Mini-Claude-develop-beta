ClaudeMini targeted source patch

Replace the included files at the same relative paths in the project.
This archive contains changed files only, not the full project.

Implemented:
- Smaller assistant text and responsive chat width for iPhone.
- Output setting can use the selected model's reported maximum instead of a separate app-side token cap. Gemini no longer reduces normal answer capacity with the old fixed 2/3 output allocation.
- More complete response and coding instructions: less outline-only output; asks for complete implementation and exact limitations.
- History selector: 1M, 5M, 10M, 25M, 50M, 100M characters.
- Up to 25 attachments per message.
- ZIP upload up to 200 MB; UTF-8 text/source files are read from the archive in memory. Extracted text is capped at 4 MB; encrypted/ZIP64 archives and binary contents inside ZIP are not parsed. No archive paths are written to disk.
- Reasoning and web search are sent through Gemini/Claude API request payloads when supported. Search is instructed to invoke the provider tool for explicit/current search requests.
- HTTP 429 detail is displayed. Permanent day/month/billing/spend quota errors do not trigger futile retry. Transient 429 retries once, preserving stream mode and honoring provider reset timing up to 15 minutes. Anthropic request/token reset headers are also read.

Important limits:
- The 24B figure is a local app counter, not API quota.
- 429 errors are provider-side rate/quota limits (for example RPM/TPM/RPD or spend limits), not the local 24B counter. Long histories and media can still consume provider input-token throughput.
- Up to 25 attachments is a count limit. Images/PDF/video sent inline are still subject to a 13 MB raw media budget per request to keep encoded request size within provider limits.
- A 100M-character history setting is a local retention ceiling, not a promise to send 100M characters in one API request. The selected model's actual context window always wins.
- ZIP max size is 200 MB, but only text/source entries are extracted and sent; total extracted text is limited to 4 MB. Binary assets inside ZIP are skipped.
- Model maximum output is read from model metadata when available. Conservative fallback values remain when the provider model list has no output-limit metadata (Gemini 8192; Claude 4096 for Claude 3 family and 8192 for other models).
- Reasoning maps to the highest level/budget supported by each provider/model. Labels such as MAX ×8 are not a literal 8x multiplier on every API.

Validation performed:
- OfficeText.c compiled with clang -std=c11 -Wall -Wextra -Werror.
- ZIP extraction was tested on a DEFLATE archive containing source/README and a binary asset; source and README were extracted, binary ignored.
- Root .git and node_modules entries were confirmed ignored.
- Vietnamese and English Localizable.strings passed plutil -lint.
- Changed Objective-C files have balanced braces/brackets/parentheses in a static check, but an Objective-C/Xcode build was not run in this Linux environment.
